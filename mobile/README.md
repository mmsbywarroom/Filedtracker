# Field Tracking — Android & iOS App

Native wrapper around the existing web app (`https://filed.videh.co.in`) with **background GPS** while punched in.

## What it does

- Loads the same dashboard (login, punch in/out, face, map)
- After punch-in, starts a **native foreground service** (Android) or **background location** (iOS)
- Every **30 minutes** (same slot rules as web): `POST /api/attendance/interval-snapshot`
- Every **2 minutes**: heartbeat to `/api/attendance/track` for admin live map
- Works with **screen off** and **other apps open** (after user grants **Always Allow** location)

## Setup

```bash
cd mobile
npm install
npm run build:plugin
npx cap add android    # first time only
npx cap add ios        # first time only (Mac)
npm run cap:sync
```

### Server URL

Default: `https://filed.videh.co.in`

Local dev:

```bash
set CAP_SERVER_URL=http://10.0.2.2:3000   # Windows Android emulator
npm run cap:sync
```

Also set in server `.env`:

```
NEXT_PUBLIC_APP_URL=https://filed.videh.co.in
```

## Android build

1. Open project: `npm run cap:open:android`
2. **Build → Generate Signed Bundle/APK**
3. On first punch-in, app asks:
   - **Location → Allow all the time**
   - **Notifications** (for foreground service)
4. Disable battery optimization: Settings → Apps → Field Tracking → Unrestricted

## iOS build (Mac)

1. `npm run cap:open:ios`
2. In Xcode → **Signing & Capabilities** → select your team
3. Add capability **Background Modes** → check **Location updates**
4. In `Info.plist` ensure:

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Field Tracking needs your location while punched in.</string>
<key>NSLocationAlwaysAndWhenInUseUsageDescription</key>
<string>Field Tracking records your location every 30 minutes while punched in, even when the app is in the background.</string>
<key>UIBackgroundModes</key>
<array>
  <string>location</string>
</array>
```

5. User must choose **Always Allow** when prompted
6. Archive → TestFlight or Ad Hoc distribution

## Permissions (user-facing)

Tell field users:

1. Install **Field Tracking** app (not only browser bookmark)
2. Login with OTP as usual
3. Punch in → tap **Allow all the time** for location
4. Keep notification *"Field Tracking active"* — do not force-stop the app

## Deploy server changes

The mobile app needs these API updates on the server:

- `GET /api/auth/mobile-token` — JWT for background requests
- `Authorization: Bearer <token>` on interval-snapshot & track APIs

```bash
git pull
npx prisma migrate deploy
docker compose up -d --build
```

## Troubleshooting

| Issue | Fix |
|-------|-----|
| No 30-min snapshots | Check **Always Allow** location; notification visible on Android |
| iOS stops after a while | User may have chosen "While Using" — re-install & pick Always |
| 401 errors in logs | Re-login in app to refresh JWT |
| Emulator has no GPS | Android Emulator → Extended controls → Location |
